# Diaz-Property-Solutions
Diaz Property Solutions helps homeowners navigate difficult real estate situations with professionalism, honesty, and compassion. We specialize in foreclosure assistance, distressed properties, creative real estate solutions, and helping homeowners explore options to protect their future.

## Deployment

The repository deploys directly from the project root as a static site on Vercel. The serverless status endpoint is available at `/api`, and the LeadConnector chat widget loads on the homepage.
